# Eve Online Player Dashboard

The goal of this project is to create a dashboard for players that they can use locally, without needing to give thier PII to other people or cloud services.

## Tech Stack

The tech stack that this project uses is:

- Frontend: Tauri
- Backend: Rust
- Database: SurrealDB (embedded)
- LLM platform: Llama.cpp
- SLM: Qwen/Qwen2.5-3B
- Embedder: nomic-ai/nomic-embed-text-v1.5
